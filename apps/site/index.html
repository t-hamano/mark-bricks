Features

Blocks or source.
One file.

Work with your entire document as blocks, using the WordPress block editor tailored for Markdown. Move things around as your document takes shape.

Switch to the code editor to edit the source. Both views work on the same Markdown document.

Style the words.
Not just the blocks.

Format text through a familiar toolbar without writing Markdown syntax. Add bold, italic, strikethrough, inline code, links, and inline images while you write.

Every style you apply shows up right in the text, just as it will look when rendered. There are no asterisks or brackets to track while you write.

Diagrams, math, and code.
With live previews.

Keep technical content alongside your writing. Mermaid diagrams and TeX formulas render in the editor, and code blocks are highlighted for the language you choose.

Select a diagram or formula to edit its source. The live preview updates instantly as you type, so you can fine-tune it without leaving the editor.

Beyond basic Markdown.
Built for richer documents.

MarkBricks supports task lists with checkboxes, collapsible details, and GitHub-style alerts for notes, tips, warnings, and more.

YAML front matter also gets its own editor at the top of the document, so titles, tags, and other metadata are easy to manage.

From Markdown notes
to presentation slides.

Add marp: true to the front matter to turn your Markdown notes into a Marp ↗︎ deck. Build slides from the same headings, images, code, and equations you already use in your notes.

Preview and present your deck in the desktop app or VS Code, then export it as HTML or PDF. Themes, page numbers, and slide dividers help you prepare the presentation.
